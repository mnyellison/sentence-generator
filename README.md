# Gerador de Frases & Citações

Um espaço simples e elegante para encontrar palavras que fazem pensar, criar e continuar.

> Projeto desenvolvido para praticar manipulação do DOM, eventos e lógica de programação com JavaScript puro.

---

## Funcionalidades da Versão Atual

- **Sorteio Aleatório:** Gere uma nova frase com autor a cada clique.
- **Modo Escuro / Claro:** Alternância de tema para melhor conforto visual.
- **Design Responsivo:** Layout adaptado para telas mobile e desktop.

---

## Tecnologias Utilizadas

- **HTML5:** Estruturação semântica da página.
- **CSS3:** Estilização, variáveis CSS para temas (Dark/Light) e layout responsivo.
- **JavaScript (ES6+):** Lógica de geração aleatória e manipulação do DOM.

---

## Conceitos Praticados

- Manipulação de arrays e geração de números aleatórios (`Math.random()`, `Math.floor()`).
- Manipulação de eventos de clique (`addEventListener`).
- Alteração dinâmica de classes e atributos no DOM via JS para troca de temas.

---

## Como Executar o Projeto

1. **Clone este repositório:**
   git clone https://github.com/mnyellison/sentence-generator.git

2. **Acesse a pasta do projeto:**
   cd sentence-generator

3. **Abra o projeto:**
   Basta abrir o arquivo `index.html` em qualquer navegador web.
